# 영단어 암기장 웹 앱 — 프로젝트 기획서

**파일 위치**: `docs/기획_261125_영단어 암기장 웹 앱 기획서 v1.0.md`
**작성일**: 2026-11-25
**버전**: v1.0
**설명**: 수업에서 만든 영단어 프로그램을 학교 서버에서 도는 웹 앱으로 다시 만드는 프로젝트의 목적·범위·일정을 정한다. (VOCA-SUB-012)

---

## 1. 배경과 목적

- 수업 시간에 Python/Tkinter 데스크톱 프로그램(영단어 암기·시험)을 만들었다. 이력은 파일(JSONL)에 저장했다.
- 기말 과제는 이를 **웹 앱**으로 다시 만들어 학교 서버에 올리는 것이다. 이력은 **DB(SQLite)** 에 저장한다.
- 목적: 단어 등록 → 암기 → 시험 → 학습 진척 확인의 한 사이클을 웹에서 끝까지 쓸 수 있게 한다.

## 2. 범위

| 구분 | 내용 |
|---|---|
| 포함(기본) | 단어 등록·수정·삭제·검색·CSV 가져오기, 일차별 암기, 시험(3형식·3방향), 학습 진척 통계, Docker 배포 |
| 제외(도전, 이번 범위 아님) | 로그인, 다른 계정 이력 보기, 설정 화면 (VOCA-FR-041~062) |
| 제외(비목표) | 모바일 최적화, 다국어, 외부 서비스 연동 |

도전 기능을 뺀 이유: 기본 기능과 제출 요건(Docker 점검 통과)이 만점 조건이고, 도전은 가산점이기 때문이다.
기본이 서버에서 안정적으로 도는 것을 먼저 확보한다. 도전 기능은 이후 별도 작업으로 추가한다.

## 3. 사용자와 환경

- 사용자: 영단어를 외우고 시험 보는 학습자 1명(로그인 없음, 한 서버에 한 DB).
- 환경: PC 크롬. 학교 서버의 Docker 컨테이너(UID 10001, 포트 8080, 인터넷 없음, 쓰기는 `/data`·`/tmp`).

## 4. 기술 선택 (요약, 근거는 설계서의 ADR)

| 항목 | 선택 |
|---|---|
| 언어·프레임워크 | Python 3.13 + Flask, 템플릿은 Jinja2, JS는 쓰지 않음 |
| DB | SQLite (`DB_PATH`) |
| 서버 | gunicorn |
| 배포 | Dockerfile + GitHub Actions 점검 워크플로 |

|---|---|
| 서버 하위 경로(`/2026/voca-<학번>/`)에서 링크가 깨짐 | 모든 주소를 따옴표로 감싼 `/` 시작 경로로 쓰고, JS·호스트·JSON 주소를 쓰지 않는다 (R-04) |
