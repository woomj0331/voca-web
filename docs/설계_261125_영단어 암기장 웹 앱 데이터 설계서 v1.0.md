# 영단어 암기장 웹 앱 — 데이터 설계서

**파일 위치**: `docs/설계_261125_영단어 암기장 웹 앱 데이터 설계서 v1.0.md`
**작성일**: 2026-11-25
**버전**: v1.0
**설명**: SQLite 테이블 정의, 제약 조건, 저장 정책, 통계 쿼리의 근거를 정의한다. (VOCA-SUB-015)

---

## 1. 개요

- DB: SQLite 3, 파일은 환경변수 `DB_PATH` (서버 `/data/voca.db`, 로컬 기본 `voca.db`).
- 테이블은 앱이 시작할 때 `CREATE TABLE IF NOT EXISTS` 로 만든다 (`db.py` `SCHEMA`). 빈 DB에서 시작할 수 있다.
- 외래키는 연결할 때마다 `PRAGMA foreign_keys = ON` 으로 켠다.
- 시각은 `YYYY-MM-DDTHH:MM:SS` 문자열(서버 로컬 시각)이다.

## 2. ER 관계

```
words 1 ──< study_log
words 1 ──< exam_items >── 1 exams
```

단어를 지우면 그 단어의 암기·시험 이력도 함께 지워진다(`ON DELETE CASCADE`).
*(이력 보존이 필요하면 삭제 대신 비활성 표시를 두는 방법이 있으나, 이번 범위에서는 단순함을 택했다.)*

## 3. 테이블

### 3.1 words — 단어 (FR-001~004)

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| id | INTEGER | PK, AUTOINCREMENT | 등록 순서. 일차별 진도 계산의 기준 |
| term | TEXT | NOT NULL, UNIQUE, COLLATE NOCASE | 영단어. 대소문자 무시 중복 금지 |
| meaning | TEXT | NOT NULL | 뜻 |
| created_at | TEXT | NOT NULL | 등록 시각 |

### 3.2 study_log — 암기 이력 (FR-014)

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| id | INTEGER | PK | |
| word_id | INTEGER | NOT NULL, FK → words.id | 외운 단어 |
| day | INTEGER | NOT NULL | 몇 일차에 외웠는지 |
| tag | TEXT | NOT NULL | `new`(신규) / `prev`(전날 복습) / `wrong`(자주 틀린 단어) |
| studied_at | TEXT | NOT NULL | 시각 |

인덱스: `idx_study_log_word(word_id)`

### 3.3 exams — 시험 회차 (FR-032)

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| id | INTEGER | PK | 회차 식별 |
| created_at | TEXT | NOT NULL | 시작 시각 |
| finished_at | TEXT | NULL 허용 | 마지막 문항을 제출한 시각. NULL 이면 진행 중이라 통계에서 제외 |
| direction | TEXT | NOT NULL | 선택한 방향 `en_ko` / `ko_en` / `mixed` |
| question_count | INTEGER | NOT NULL | 문항 수 |

### 3.4 exam_items — 시험 문항 이력 (FR-025, 026)

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| id | INTEGER | PK | |
| exam_id | INTEGER | NOT NULL, FK → exams.id | |
| seq | INTEGER | NOT NULL | 문항 번호(1부터) |
| word_id | INTEGER | NOT NULL, FK → words.id | 출제 단어 |
| qtype | TEXT | NOT NULL | 형식 `short` / `mc4` / `ox` |
| direction | TEXT | NOT NULL | 이 문항의 실제 방향(`mixed` 도 문항마다 한쪽으로 정해짐) |
| prompt | TEXT | NOT NULL | 문제 문장 |
| choices_json | TEXT | | 4지선다 보기 목록(JSON) |
| answer_json | TEXT | NOT NULL | 정답(JSON). short=문자열, mc4=보기 번호, ox="O"/"X" |
| shown | TEXT | | OX 에서 제시한 짝 |
| response_json | TEXT | | 사용자의 응답 |
| correct | INTEGER | NULL 허용 | 1 정답 / 0 오답 / NULL 아직 안 풂 |
| answered_at | TEXT | | 답한 시각 |

인덱스: `idx_exam_items_word(word_id)`, `idx_exam_items_exam(exam_id, seq)`

## 4. 통계 쿼리 (FR-031~034, 모두 이력 집계)

| 통계 | 함수 | 근거 |
|---|---|---|
| 현재 일차 | `store.progress_summary` | `MAX(study_log.day)` (없으면 1) |
| 암기한 단어 수 / 전체 | `store.progress_summary` | `COUNT(DISTINCT study_log.word_id)` / `COUNT(words)` |
| 회차별 정답률 | `store.score_by_exam` | `exams` ⨝ `exam_items`, `finished_at IS NOT NULL`, `exams.id` 별 `SUM(correct)/COUNT(*)` |
| 날짜별 정답률 | `store.score_by_date` | `substr(answered_at,1,10)` 별 집계 |
| 자주 틀리는 단어 | `store.top_wrong_words` | 단어별 `SUM(1-correct)` 내림차순, 같으면 오답률 순, 상위 10개 |
| 출제 가중치 입력 | `store.test_stats` | 단어별 시도·오답·마지막 시각 |

## 5. 저장 정책

- 쓰기는 `/data` 에만 한다(SQLite 파일). 업로드한 CSV 는 파일로 저장하지 않고 메모리에서 읽는다.
- CSV 는 `utf-8-sig`(BOM) 로 읽는다. 5MB 초과는 거절한다.
- 컨테이너를 재시작해도 `/data` 가 유지되는 한 이력은 남는다.
- DB 파일(`*.db`)은 `.gitignore`, `.dockerignore` 로 리포·이미지에서 뺀다.
