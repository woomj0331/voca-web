## 1. 구성

```
브라우저(PC 크롬)
   │  HTTP  (서버가 /2026/voca-<학번>/ 를 떼고 넘김)
   ▼
[컨테이너: python:3.13-slim, UID 10001]
   gunicorn (0.0.0.0:8080, worker 2)
      └─ Flask 앱 app:app
           ├─ app.py        라우트·화면 조립
           ├─ store.py      SQL 읽기/쓰기, 통계 집계
           ├─ exam.py       출제 가중치·문제 생성·채점 (순수 함수)
           ├─ study_plan.py 일차별 암기 계획 (순수 함수)
           └─ db.py         SQLite 연결·테이블 생성
                     │
                     ▼
              /data/voca.db  (SQLite, 환경변수 DB_PATH)
```

계층 원칙: 화면(`app.py`)은 SQL 을 직접 쓰지 않고, 계산 로직(`exam.py`, `study_plan.py`)은 DB·웹을 모른다.
그래서 계산 로직은 DB 없이 단위 테스트할 수 있다.

## 3. 핵심 흐름

**암기**: `GET /study?day=N&per_day=M&i=K` → 단어 전체와 시험 이력 요약으로 N일차 계획을 만들고 K번째 카드를 보여 준다.
`뜻 보기`는 HTML `<details>` 로 펼친다(JS 없음). `다음`을 누르면 `POST /study/next` 가 `study_log` 에 한 줄을 남기고 K+1번 카드로 이동한다.

**시험**: `POST /exam/start` 에서 가중치로 단어를 뽑고 **문제를 모두 만들어 DB에 저장**한다(`exams`, `exam_items`).
이후 화면은 DB에서 K번 문항을 읽어 보여 주고, 답을 제출하면 채점해 같은 행에 응답·정오·시각을 기록한다.
마지막 문항을 제출하면 시험을 끝내고 결과 화면으로 이동한다. 이미 답한 문항은 다시 채점하지 않는다.

**출제 가중치**: `w = 1 + (본 적 없음 3) + (7일 넘게 안 봄 2) + 4 × 오답률`. 가중치에 비례해 중복 없이 뽑는다.
방법은 단어마다 `u ** (1/w)` (u는 0~1 난수)를 계산해 큰 순서로 고르는 것이다.

## 5. 결정 기록 (ADR)

### ADR-1 프레임워크: Flask + 서버 렌더링

- **배경**: 기존 데스크톱판이 Python 이라 출제·계획 로직을 그대로 옮길 수 있다. 과제 안내도 서버 템플릿과 바닐라 JS로 충분하다고 한다.
- **대안**: FastAPI(자동 문서가 장점이나 템플릿 화면에는 이점이 적음), Express(로직을 다시 짜야 함), React 등 SPA(빌드 단계와 경로 문제가 늘어남).
- **결정 근거**: 로직 재사용, 의존성 최소(Flask, gunicorn 2개), 서버가 경로를 바꿔 주는 환경에서 주소 문제가 가장 적다. JS를 쓰지 않아 R-04 ③(JS 주소 변수) 위반 가능성이 없다.

### ADR-2 시험 문제를 세션이 아닌 DB에 저장

- **배경**: 시험은 여러 요청에 걸쳐 진행된다. 세션(쿠키)에 문제를 두면 `SECRET_KEY` 가 필요하고, 워커가 2개일 때 키가 다르면 세션이 깨진다. 쿠키 경로도 하위 경로 문제를 일으킬 수 있다.
- **대안**: 서명 쿠키 세션, 서버 메모리 캐시.
- **결정 근거**: 문제를 시작할 때 모두 `exam_items` 에 저장하면 워커 수와 무관하고, 새로고침·재시작 후에도 이어 풀 수 있다. 문항 단위 이력(FR-026)도 같은 표로 해결된다.

### ADR-3 CSV 중복 처리: 기존 단어 유지, 새 행 건너뜀

- **배경**: FR-003 은 중복 처리 방식을 직접 정하고 적도록 한다. 영단어는 대소문자를 구분하지 않고 같은 단어로 본다(`COLLATE NOCASE UNIQUE`).
- **대안**: 새 뜻으로 덮어쓰기, 뜻을 합치기, 중복 단어를 별도 표시.
- **결정 근거**: 이미 외우고 시험 본 단어의 이력(`word_id` 로 연결)을 보존해야 한다. 덮어쓰면 사용자가 고친 뜻이 사라질 수 있다. 건너뛴 개수는 가져오기 결과 메시지로 알려 준다.

### ADR-4 안내 메시지는 쿼리 문자열로 전달

- **배경**: Flask `flash` 는 세션(쿠키)이 필요하다. ADR-2 와 같은 이유로 세션을 쓰지 않기로 했다.
- **결정**: 리다이렉트 때 `?msg=...` 로 넘기고 템플릿의 자동 이스케이프로 출력한다. 메시지는 화면 표시용 글자일 뿐 권한·상태에 영향을 주지 않는다.

### ADR-5 gunicorn worker 2개 + SQLite

- **결정 근거**: 이 앱은 쓰기가 적고 학습자 1명 규모이다. SQLite 기본 잠금과 10초 대기로 충분하다. 시작 시 두 워커가 동시에 `CREATE TABLE IF NOT EXISTS` 를 실행해도 안전하다.
