# 영단어 암기장 (voca-web)

영단어를 등록하고, 일차별로 암기하고, 시험을 보고, 학습 진척을 통계로 확인하는 웹 앱입니다.
수업에서 만든 데스크톱 프로그램(Tkinter)을 웹 앱(Flask)으로 다시 만들었습니다. 이력은 SQLite DB에 저장합니다.

## 기능

| 화면 | 할 수 있는 일 |
|---|---|
| 단어 | 직접 등록, 수정·삭제, 영단어/뜻 검색, CSV 가져오기(중복은 기존 뜻 유지) |
| 암기 | 하루 학습량(기본 10개)으로 N일차 진도 생성. 카드로 영단어 → 뜻 보기. 전날 단어 30%와 자주 틀린 단어를 섞음 |
| 시험 | 문제 수·방향(영→한/한→영/섞기)·형식(단답형/4지선다/OX) 선택. 안 본 단어·오래된 단어·자주 틀린 단어를 더 자주 출제. 점수와 틀린 문항·정답 표시 |
| 통계 | 진도 현황, 회차별·날짜별 정답률, 자주 틀리는 단어 TOP 10 (모두 DB 이력으로 계산) |

## 실행 방법

### Docker (서버와 같은 방식)

```bash
docker build -t voca-web .
docker run --rm -p 8080:8080 -v voca-data:/data voca-web
```

http://localhost:8080 을 엽니다. 이력은 `voca-data` 볼륨의 `/data/voca.db` 에 저장됩니다.

### 로컬 (개발용)

```bash
pip install -r requirements.txt
python app.py
```

http://localhost:8080 을 엽니다. DB 는 현재 폴더의 `voca.db` 에 생깁니다. 위치는 환경변수 `DB_PATH` 로 바꿉니다.

### 테스트

```bash
python -m unittest discover -s tests
```

## 처음 쓰는 방법

1. **단어** 화면에서 `samples/sample_words.csv` 를 가져오거나 단어를 직접 등록합니다.
2. **암기** 화면에서 1일차를 시작합니다.
3. **시험** 화면에서 문제 수와 형식을 고르고 시험을 봅니다.
4. **통계** 화면에서 결과를 확인합니다.

## 고른 DB

**SQLite** (`DB_PATH`, 서버 `/data/voca.db`). 앱을 처음 실행하면 테이블이 자동으로 만들어집니다.
